# Bella Tavola

A responsive restaurant website for Bella Tavola, built with HTML, CSS, and Vite. Done in completion of the first assignment of Mayerfeld Consulting's UI Developer Practicum.

## Getting Started

Install dependencies and start the development server:

```sh
pnpm install
pnpm dev
```

Create a production build with:

```sh
pnpm build
```

## Deployment

The site is deployed to GitHub Pages automatically when changes are pushed to `main`.

https://ja-uyoma.github.io/restaurant/
